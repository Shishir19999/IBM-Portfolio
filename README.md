# IBM Portfolio

A single-page personal portfolio (HTML, CSS, vanilla JavaScript).

- `index.html` - sections: About Me, Skills, Projects, Recommendations, and a "Leave a Recommendation" form
- `style.css` - styles, including responsive rules for screens up to 992px and 600px
- `script.js` - adds new recommendations to the page (text is inserted safely, not as HTML) and shows a thank-you popup
- `images/` - icons and the profile animation

Open `index.html` in a browser. Recommendations added in the form are not saved (they disappear on reload).
